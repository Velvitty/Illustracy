# Illustracy

완성된 일러스트 한 장을 **작가가 실제로 레이어를 나눠 그리는 방식대로**
(파츠별 밑색 → 1차·2차 그림자 → 하이라이트, 명암, 효과, 선화 + 색트레스, 러프) 분리해
Photoshop PSD 파일로 저장하는 브라우저 도구입니다.

- `index.html` 파일 하나에 HTML · CSS · JS가 모두 들어 있습니다. 설치, 서버, 외부 라이브러리, 유료 API가 필요 없습니다.
- 모든 처리는 브라우저 안에서 이루어지며 이미지는 어디에도 업로드되지 않습니다.
- 분리된 레이어를 다시 합성하면 원본과 거의 같습니다(예제 그림 기준 PSNR 약 55 dB).

## 오프라인 실행

1. `index.html`을 내려받습니다(GitHub에서 파일을 열고 *Download raw file*, 또는 저장소 ZIP 다운로드).
   이미 웹에서 열어 둔 상태라면 왼쪽 위 **⬇ 프로그램 저장 (오프라인 실행용)** 버튼으로 같은 파일을 받을 수 있습니다.
2. 받은 파일을 더블클릭해 브라우저로 엽니다. 인터넷 연결 없이 모든 기능이 동작합니다.

네트워크 요청을 전부 막은 상태와 브라우저를 오프라인으로 둔 상태에서 테스트했습니다(외부 요청 0건).

## 사용법

1. `index.html`을 Chrome / Edge / Firefox / Safari에서 엽니다.
2. 이미지를 끌어다 놓거나, 클릭해서 고르거나, `Ctrl+V`로 붙여넣습니다. **예제 그림** 버튼으로 바로 시험해 볼 수 있습니다.
3. 자동으로 분리가 실행됩니다. 오른쪽 레이어 패널에서
   - 눈 아이콘: 표시/숨김
   - 레이어 클릭: 혼합 모드 · 불투명도 변경, 해당 레이어만 PNG로 저장
   - 이름 더블클릭: 이름 변경
4. **PSD 다운로드**를 누르면 패널에서 바꾼 내용(이름, 혼합 모드, 불투명도, 표시 여부)이 그대로 PSD에 반영됩니다.

미리보기 상단의 `합성 / 원본 / 선택 레이어 / 차이 ×8`로 결과를 비교할 수 있고, 휠로 확대 · 드래그로 이동합니다.

### 배경으로 보내기 (수동 보정)

자동 판정이 캐릭터 쪽에 남긴 배경 물건(탁자, 의자, 소품 등)은 직접 배경으로 옮길 수 있습니다.

1. 미리보기 위의 **배경으로 보내기**를 켭니다.
2. 옮길 물건을 클릭하거나 문질러 칠합니다. 획을 따라 옅은 분홍 띠가 보이고, 그 띠 안에서
   **획이 닿은 파츠(밑색)와 그와 거의 같은 색(ΔE<12)의 파츠 안에서, 선을 넘지 않고 색이 이어지는 부분**만 옮겨집니다.
   - 의자 다리처럼 밝은 면 · 어두운 면이 여러 파츠로 나뉜 물건도 다리를 따라 한 번 칠하면 통째로 옮겨집니다.
   - 선 없이 맞닿은 어두운 탁자 모서리(ΔE 13)와 검은 치마는 섞이지 않고, 캐릭터를 살짝 스쳐도 파츠 전체가 딸려 오지 않습니다.
3. 잘못 옮겼으면 `↶` 버튼이나 `Ctrl+Z`로 되돌립니다. 이 모드에서 화면 이동은 오른쪽 버튼 드래그입니다.

옮긴 부분은 배경 레이어에 원본 색 그대로 들어가고 캐릭터 쪽 레이어(밑색 · 그림자 · 명암 · 선화 …)에서는 지워지므로,
합성 결과는 그대로 원본과 같고 PSD에도 그대로 반영됩니다.

## 레이어 구성 (위 → 아래)

현직 작가의 작업 파일 구성을 따릅니다. 캐릭터와 배경을 폴더로 나누고, 파츠(같은 밑색으로 칠한 부분)마다
밑색 위에 그림자와 하이라이트를 **클리핑**해서 쌓습니다.

```
러프 (추정)                 표준 45%, 숨김   완성본에서 역으로 만든 추정 스케치
[캐릭터]
  [선화]
    색트레스                표준, ↳클리핑    선 색이 다른 부분만(빛을 받은 선, 색 선 등)
    선화                    표준             한 가지 색의 선 + 안티에일리어싱 알파
  [효과]
    반짝임                  스크린           작고 밝은 점, 가는 광택(눈 하이라이트, 별, 스파클)
    빛                      스크린           넓게 퍼진 빛 · 글로우
  [채색]
    림라이트                스크린           실루엣 가장자리에만 몰린 역광
    반사광                  스크린           그림자 속에서 다시 밝아진 부분
    명암                    곱하기           파츠 단위로 설명되지 않는 부드러운 음영
    그라데이션              곱하기           넓게 깔린 저주파 음영(아래로 갈수록 어두워지는 등)
    [피부] [보라] …         파츠 폴더(밑색 색 이름으로 자동 명명, 피부색은 "피부")
      하이라이트            표준, ↳클리핑    밑색보다 확실히 밝은 면(머리카락 광택 등)
      2차 그림자            곱하기, ↳클리핑  1차 그림자 안의 더 어두운 그림자
      1차 그림자            곱하기, ↳클리핑  셀 그림자 — 파츠마다 한 가지 색
      밑색 #7B56B5          표준             선 안쪽까지 빈틈없이 칠한 단색
    실루엣 (선택용)         표준, 숨김       캐릭터 전체 모양(선택 영역·클리핑 기준용)
[배경]
  배경 효과                 스크린           배경 위에 떠 있는 입자 · 빛줄기 조각
  배경                      표준             테두리와 이어진 배경(감지된 경우)
```

- 요청한 레이어(러프 · 선화 · 채색 · 그림자 · 명암 · 반짝임 · 효과) 외에 실제 작업 파일에서 흔히 나누는
  **색트레스 · 하이라이트 · 2차 그림자 · 그라데이션 · 반사광 · 림라이트 · 빛 · 배경 효과 · 실루엣**과
  **[캐릭터] · [배경] · [선화] · 파츠 폴더** 계층을 추가했습니다.
- 모든 레이어는 이름에 맞는 내용을 실제로 담고 있고, 다 합치면 원본이 됩니다. 그림에 해당 내용이 거의 없으면
  (예: 셀 채색 그림의 그라데이션 · 반사광) 따로 만들지 않고 명암 · 빛에 남깁니다. 빈 자리만 채우는 레이어는 만들지 않습니다.
- 배경이 감지되지 않은 불투명한 그림은 [캐릭터] · [배경] 폴더 없이 [선화] · [효과] · [채색]이 맨 위에 옵니다.
- 옵션으로 파츠 폴더 없이 밑색 · 1차 그림자 · 2차 그림자 · 하이라이트를 한 장씩으로 모을 수도 있습니다.

## 동작 원리

1. **선화 검출** — 밝기의 블랙 탑햇(closing − 원본)으로 얇고 어두운 구조만 뽑고, 히스테리시스로 이어 붙입니다.
   선 교차점처럼 넓어진 부분은 선에서 이어서 채웁니다.
2. **선 아래 색 복원** — 선 영역을 바깥쪽부터 한 겹씩 이웃 색으로 채웁니다(인페인팅).
3. **선화 + 색트레스** — 선이 완전히 덮은 픽셀들의 색 중앙값을 기본 선 색으로 정하고,
   `원본 = 알파 × 선색 + (1 − 알파) × 아래색`을 풀어 알파를 구합니다. 기본 선 색으로 맞지 않는 곳(색 선, 빛 받은 선)은
   부드러운 선 색에서 출발하되 원본이 정확히 재현되는 최소 알파 이상으로 알파를 잡아 색트레스에 넣습니다.
4. **배경 분리** — 이미지 테두리의 대표 색에서 시작해 선을 넘지 않고 비슷한 색으로 퍼져 나갑니다.
   테두리를 따라 색이 이어지는 그라데이션도 따라가되, 윤곽선을 만나면 멈춥니다.
   배경 위에 떠 있는 작은 조각(입자, 빛줄기 조각)은 아래 배경색을 추정해 배경에 두고 밝아진 만큼을 효과로 보냅니다.
   배경으로 둘러싸인 배경색 "선"(빛줄기 사이로 보이는 배경 틈)과 캐릭터에서 멀리 떨어진 배경 속 선(창틀, 구름, 크레이터)은
   선화에서 빼서 배경 그림에 남깁니다.
   **장면 배경**(커튼, 교실, 우주처럼 색이 한 가지가 아닌 배경)은 두 단계로 찾습니다.
   1. "캐릭터·소품은 선으로 그리고 배경은 선 없이 칠한다" — 선 밀도가 낮은 곳 중 테두리와 이어진 영역.
      선 밀도를 흐려서 쓰므로 모든 선 둘레에 두꺼운 띠가 생겨 윤곽선의 작은 틈으로 새지 않습니다.
   2. "캐릭터 선은 진하고 또렷하며, 배경은 흐리게(피사계 심도) 또는 잔 결로 그린다" — 살짝 흐렸을 때 깊이가 크게 줄어드는
      진하고 또렷한 선만 "선명한 선"으로 보고, 1단계 배경(또는 위·왼쪽·오른쪽 테두리)에서 출발해 선명한 선은 없고
      흐린 자국만 빽빽한 곳(선반, 글씨, 카펫 무늬)으로 넓힙니다. 아래 테두리는 캐릭터가 잘려 있는 경우가 많아 출발점으로 쓰지 않습니다.
   그다음 색이 매끄럽게 이어지는 곳까지 윤곽선 직전까지 넓히고, 배경에 흡수된 흐린 자국은 선화에서 빼서 배경 그림에 남깁니다.
5. **재질 분할** — Lab 색공간 k-means → 연결 영역 → 인접 그래프. 두 영역의 경계가 **선으로 막혀 있지 않고**
   색이 같은 재질의 명암 관계라면 같은 재질로 묶습니다. 셀 채색에서 재질 경계에는 선이 있고
   그림자 경계에는 선이 없다는 점을 이용합니다.
6. **톤 분석** — 재질마다 다시 군집화해 톤을 나누고, 가장 넓은 톤을 밑색으로 삼습니다.
   선으로 나뉜 같은 재질(앞머리/뒷머리 등)은 밑색을 맞춥니다.
7. **파츠 정리** — 실제 작업 파일처럼 파츠 수를 줄입니다. 거의 같은 밑색은 한 파츠로,
   선 건너편의 더 어두운 면이 그럴듯한 그림자라면(흰 머리카락 옆 연보라 가닥) 밝은 파츠의 그림자로,
   작은 조각은 이웃 파츠로 합치고, 파츠는 최대 24개로 제한합니다.
8. **그림자 단계** — 파츠 안의 그림자 톤을 밝기로 정렬해 틈이 큰 곳에서 1차/2차로 나누고,
   단계마다 한 가지 곱하기 색을 정합니다(2차는 1차 위에 한 번 더 곱해지는 색).
9. **역산** — 픽셀마다 `밑색 × 1차 × 2차 → 하이라이트(표준) → 그라데이션 × 명암(곱하기) → 반사광 · 림라이트 · 반짝임 · 빛(스크린) → 선화`로
   원본이 나오도록 남은 차이를 계산합니다.
   - 어두워짐은 넓게 깔린 부분(침식 + 흐림으로 구한 아래 포락선)을 그라데이션으로, 나머지를 명암으로 나눕니다.
   - 밝아짐은 스크린이 `1-(1-a)(1-b)`로 합쳐지는 성질을 이용해 차례로 떼어 냅니다:
     작은 밝은 조각 → 실루엣 가장자리에서만 확 밝은 부분(림라이트) → 가는 밝은 선(반짝임) → 그림자 속 밝아짐(반사광) → 나머지(빛).
   - 반짝임은 그림 자체에서 주변보다 확 튀는 옅은 색의 점·가는 광택만 인정합니다(화이트 탑햇).
     피부·머리카락처럼 넓게 칠한 밝은 결은 빛으로 갑니다.
10. **PSD 작성** — 자체 구현한 작성기(RGB 8비트, PackBits RLE, 중첩 그룹, 클리핑, 혼합 모드, 유니코드 이름, 병합 이미지)로 저장합니다.
   psd-tools(Python)와 ag-psd(JS) 두 파서로 구조와 합성 결과를 검증했습니다.

무거운 계산은 Web Worker에서 돌고, 워커를 쓸 수 없는 환경에서는 메인 스레드에서 처리합니다.
미리보기도 Photoshop과 같은 방식(클리핑 그룹을 먼저 합성한 뒤 기본 레이어 알파로 자름)으로 합성합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| 처리 해상도 | 긴 변 기준으로 줄여서 처리(기본 2048px). 2048px 기준 약 6~8초 |
| 선 감도 | 높일수록 옅은 선까지 선화로 봄 |
| 최대 선 굵기 | 이보다 두꺼운 어두운 영역은 선이 아닌 면으로 봄(0 = 해상도에 맞춰 자동) |
| 선 색상 | 선화 + 색트레스(기본) / 원본 선 색 그대로 한 장 / 검정 단색 |
| 색상 군집 수 | 처음 영역을 나눌 때의 색 개수 |
| 밑색 병합 강도 | 높을수록 음영 톤을 같은 밑색으로 적극적으로 묶음 |
| 그림자 판정 기준 | 높을수록 옅은 음영도 그림자 레이어로 보냄 |
| 반짝임 최대 크기 | 이보다 작은 밝은 점을 반짝임으로 봄 |
| 파츠별 폴더 | 끄면 밑색 · 그림자 · 하이라이트를 파츠 구분 없이 한 장씩으로 |
| 클리핑 | 그림자 · 하이라이트를 밑색에 클리핑 |

## 한계

- 인공지능 모델이 아닌 영상 처리 휴리스틱입니다. **선이 있는 셀 채색** 그림에서 가장 잘 동작하고,
  선이 없거나 브러시로 칠한 그림은 밑색이 여러 톤으로 나뉘거나 음영이 명암 레이어로 많이 넘어갈 수 있습니다.
- 러프는 원본에 존재하지 않으므로 완성본에서 **생성한 추정 스케치**입니다(기본 숨김).
- 선 아래에 가려진 색은 주변에서 추정한 값입니다. 선 두 개 사이의 1~2px 틈 같은 곳은 오차가 남을 수 있습니다.
- 파츠 이름은 밑색으로 붙인 색 이름(피부, 보라, 파랑 …)이며 "머리카락", "옷" 같은 의미는 알지 못합니다.
- 빛 · 반짝임은 선화 아래에 둡니다(원본을 정확히 재현하기 위해). 선 위에 빛이 칠해진 그림은 그 부분이 색트레스로 들어갑니다.
- 어두운 배경 앞의 어두운 옷처럼 색이 거의 같은 곳에서는 옷이 배경으로 새지 않도록 배경을 보수적으로 잡습니다.
  그래서 멀리 떨어진 밝은 배경 그라데이션 일부가 파츠로 남을 수 있습니다.
- 머리카락 사이로 보이는 배경 틈처럼 선으로 둘러싸인 배경 조각은 배경이 아니라 그 파츠의 명암으로 들어갈 수 있습니다.
- 피부와 머리카락이 거의 같은 색이면 한 파츠로 합쳐집니다.
- 장면 배경 판정은 "선이 없는 곳"을 기준으로 하므로, 배경과 같은 색이라 윤곽선이 거의 안 보이는 가는 소품(지팡이 등)이나
  화면 가장자리에서 잘린 선 없는 부분(치마 아랫부분 등)은 배경으로 들어갈 수 있습니다. 책상 같은 큰 소품도 배경에 들어갈 수 있습니다.
- 명암 차이만으로 재질을 가르기 어려운 저채도 그림에서는, 확신이 없으면 다른 재질을 그림자로 합치지 않고 파츠를 따로 둡니다.
- 배경을 세밀하게 그린 그림에서, 흐리게 그린 결(선반, 글씨, 카펫 무늬)은 배경으로 가르지만(카페 실내 그림: 배경 19% → 41%)
  캐릭터 선만큼 진하고 또렷한 윤곽을 가진 배경 물건(탁자, 의자, 앞쪽 선반)은 자동으로는 캐릭터 쪽 파츠로 남습니다.
  이런 물건은 **배경으로 보내기**로 옮깁니다(카페 실내 그림: 탁자 · 의자 10획 정도로 배경 41% → 58%, 의자 다리는 다리마다 한 획).
- 탁자 바로 밑에 드리운 치마의 그림자처럼, 자동 분리에서 탁자와 같은 파츠로 묶이고 선도 없는 부분은 붓 폭 안에서 함께 옮겨질 수 있습니다.
  그럴 때는 되돌린 뒤 조금 떨어뜨려 칠하면 됩니다.
- 나뭇잎 사이 햇빛처럼 강한 빛 얼룩이 캐릭터 위에 드리우면 밑색 파츠가 조각나기 쉽습니다(빛 얼룩 자체는 빛 레이어로 갑니다).
