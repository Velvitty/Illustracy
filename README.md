# Illustracy

완성된 일러스트 한 장을 **작가가 실제로 레이어를 나눠 그리는 방식대로**
(파츠별 밑색 → 1차·2차 그림자 → 하이라이트, 명암, 효과, 선화 + 색트레스, 러프) 분리해
Photoshop PSD 파일로 저장하는 브라우저 도구입니다.

- `index.html` 파일 하나에 HTML · CSS · JS가 모두 들어 있습니다. 설치, 서버, 외부 라이브러리, 유료 API가 필요 없습니다.
- 모든 처리는 브라우저 안에서 이루어지며 이미지는 어디에도 업로드되지 않습니다.
- 분리된 레이어를 다시 합성하면 원본과 거의 같습니다(예제 그림 기준 PSNR 약 55 dB).

## 오프라인 실행

1. `index.html`을 내려받습니다(GitHub에서 파일을 열고 *Download raw file*, 또는 저장소 ZIP 다운로드).
   이미 웹에서 열어 둔 상태라면 왼쪽 위 **⬇ 프로그램 저장 (오프라인 실행용)** 버튼으로 같은 파일을 받을 수 있습니다.
2. 받은 파일을 더블클릭해 브라우저로 엽니다. 인터넷 연결 없이 모든 기능이 동작합니다.

네트워크 요청을 전부 막은 상태와 브라우저를 오프라인으로 둔 상태에서 테스트했습니다(외부 요청 0건).

## 사용법

1. `index.html`을 Chrome / Edge / Firefox / Safari에서 엽니다.
2. 이미지를 끌어다 놓거나, 클릭해서 고르거나, `Ctrl+V`로 붙여넣습니다. **예제 그림** 버튼으로 바로 시험해 볼 수 있습니다.
3. 자동으로 분리가 실행됩니다. 오른쪽 레이어 패널에서
   - 눈 아이콘: 표시/숨김
   - 레이어 클릭: 혼합 모드 · 불투명도 변경, 해당 레이어만 PNG로 저장
   - 이름 더블클릭: 이름 변경
4. **PSD 다운로드**를 누르면 패널에서 바꾼 내용(이름, 혼합 모드, 불투명도, 표시 여부)이 그대로 PSD에 반영됩니다.

미리보기 상단의 `합성 / 원본 / 선택 레이어 / 차이 ×8`로 결과를 비교할 수 있고, 휠로 확대 · 드래그로 이동합니다.

## 레이어 구성 (위 → 아래)

작가가 칠하는 순서를 그대로 따릅니다. 파츠(같은 밑색으로 칠한 부분)마다 폴더를 만들고,
밑색 위에 그림자와 하이라이트를 **클리핑**해서 쌓습니다.

```
러프 (추정)            표준 45%, 숨김   완성본에서 역으로 만든 추정 스케치
색트레스               표준, ↳클리핑    선 색이 다른 부분만(빛을 받은 선, 색 선 등)
선화                   표준             한 가지 색의 선 + 안티에일리어싱 알파
[효과]
  반짝임               스크린           작고 밝은 점(눈 하이라이트, 별, 스파클)
  빛                   스크린           넓게 퍼진 빛 · 글로우
[채색]
  명암                 곱하기           파츠 단위로 설명되지 않는 부드러운 음영
  [피부] [보라] …      파츠 폴더(밑색 색 이름으로 자동 명명, 피부색은 "피부")
    하이라이트         표준, ↳클리핑    밑색보다 확실히 밝은 면(머리카락 광택 등)
    2차 그림자         곱하기, ↳클리핑  1차 그림자 안의 더 어두운 그림자
    1차 그림자         곱하기, ↳클리핑  셀 그림자 — 파츠마다 한 가지 색
    밑색 #7B56B5       표준             선 안쪽까지 빈틈없이 칠한 단색
배경                   표준             테두리와 이어진 단색/완만한 그라데이션 배경(감지된 경우)
```

- 거의 비어 있는 보조 레이어(명암 · 빛 · 반짝임 · 색트레스)는 만들지 않습니다.
- 선 색이 모두 같으면 색트레스 없이 선화 한 장만 만듭니다.
- 옵션으로 파츠 폴더 없이 밑색 · 1차 그림자 · 2차 그림자 · 하이라이트를 한 장씩으로 모을 수도 있습니다.

## 동작 원리

1. **선화 검출** — 밝기의 블랙 탑햇(closing − 원본)으로 얇고 어두운 구조만 뽑고, 히스테리시스로 이어 붙입니다.
   선 교차점처럼 넓어진 부분은 선에서 이어서 채웁니다.
2. **선 아래 색 복원** — 선 영역을 바깥쪽부터 한 겹씩 이웃 색으로 채웁니다(인페인팅).
3. **선화 + 색트레스** — 선이 완전히 덮은 픽셀들의 색 중앙값을 기본 선 색으로 정하고,
   `원본 = 알파 × 선색 + (1 − 알파) × 아래색`을 최소제곱으로 풀어 알파를 구합니다.
   실제 선 색이 기본 선 색과 확실히 다른 곳만 색트레스 레이어에 남깁니다.
4. **배경 분리** — 이미지 테두리의 대표 색에서 시작해 선을 넘지 않고 비슷한 색으로 퍼져 나갑니다.
5. **재질 분할** — Lab 색공간 k-means → 연결 영역 → 인접 그래프. 두 영역의 경계가 **선으로 막혀 있지 않고**
   색이 같은 재질의 명암 관계라면 같은 재질로 묶습니다. 셀 채색에서 재질 경계에는 선이 있고
   그림자 경계에는 선이 없다는 점을 이용합니다.
6. **톤 분석** — 재질마다 다시 군집화해 톤을 나누고, 가장 넓은 톤을 밑색으로 삼습니다.
   선으로 나뉜 같은 재질(앞머리/뒷머리 등)은 밑색을 맞추고, 밑색이 같은 재질은 하나의 파츠가 됩니다.
7. **그림자 단계** — 파츠 안의 그림자 톤을 밝기로 정렬해 틈이 큰 곳에서 1차/2차로 나누고,
   단계마다 한 가지 곱하기 색을 정합니다(2차는 1차 위에 한 번 더 곱해지는 색).
8. **역산** — 픽셀마다 `밑색 × 1차 × 2차 → 하이라이트(표준) → 명암(곱하기) → 빛 · 반짝임(스크린) → 선화`로
   원본이 나오도록 남은 차이를 계산합니다. 남는 밝아짐은 화이트 탑햇과 조각 크기로 반짝임과 빛으로 나눕니다.
9. **PSD 작성** — 자체 구현한 작성기(RGB 8비트, PackBits RLE, 중첩 그룹, 클리핑, 혼합 모드, 유니코드 이름, 병합 이미지)로 저장합니다.
   psd-tools(Python)와 ag-psd(JS) 두 파서로 구조와 합성 결과를 검증했습니다.

무거운 계산은 Web Worker에서 돌고, 워커를 쓸 수 없는 환경에서는 메인 스레드에서 처리합니다.
미리보기도 Photoshop과 같은 방식(클리핑 그룹을 먼저 합성한 뒤 기본 레이어 알파로 자름)으로 합성합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| 처리 해상도 | 긴 변 기준으로 줄여서 처리(기본 2048px). 2048px 기준 약 6~8초 |
| 선 감도 | 높일수록 옅은 선까지 선화로 봄 |
| 최대 선 굵기 | 이보다 두꺼운 어두운 영역은 선이 아닌 면으로 봄(0 = 해상도에 맞춰 자동) |
| 선 색상 | 선화 + 색트레스(기본) / 원본 선 색 그대로 한 장 / 검정 단색 |
| 색상 군집 수 | 처음 영역을 나눌 때의 색 개수 |
| 밑색 병합 강도 | 높을수록 음영 톤을 같은 밑색으로 적극적으로 묶음 |
| 그림자 판정 기준 | 높을수록 옅은 음영도 그림자 레이어로 보냄 |
| 반짝임 최대 크기 | 이보다 작은 밝은 점을 반짝임으로 봄 |
| 파츠별 폴더 | 끄면 밑색 · 그림자 · 하이라이트를 파츠 구분 없이 한 장씩으로 |
| 클리핑 | 그림자 · 하이라이트를 밑색에 클리핑 |

## 한계

- 인공지능 모델이 아닌 영상 처리 휴리스틱입니다. **선이 있는 셀 채색** 그림에서 가장 잘 동작하고,
  선이 없거나 브러시로 칠한 그림은 밑색이 여러 톤으로 나뉘거나 음영이 명암 레이어로 많이 넘어갈 수 있습니다.
- 러프는 원본에 존재하지 않으므로 완성본에서 **생성한 추정 스케치**입니다(기본 숨김).
- 선 아래에 가려진 색은 주변에서 추정한 값입니다. 선 두 개 사이의 1~2px 틈 같은 곳은 오차가 남을 수 있습니다.
- 파츠 이름은 밑색으로 붙인 색 이름(피부, 보라, 파랑 …)이며 "머리카락", "옷" 같은 의미는 알지 못합니다.
- 빛 · 반짝임은 선화 아래에 둡니다(원본을 정확히 재현하기 위해). 선 위에 빛이 칠해진 그림은 그 부분이 색트레스로 들어갑니다.
- 반투명 가장자리(투명 배경 PNG의 외곽)는 근사 처리됩니다.
