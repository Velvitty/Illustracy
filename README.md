# Illustracy

완성된 일러스트 한 장을 **선화 · 채색 · 그림자 · 명암 · 하이라이트 · 반짝임 · 효과 · 러프** 레이어로 분리해
Photoshop PSD 파일로 저장하는 브라우저 도구입니다.

- `index.html` 파일 하나에 HTML · CSS · JS가 모두 들어 있습니다. 설치나 서버, 외부 라이브러리가 필요 없습니다.
- 모든 처리는 브라우저 안에서 이루어지며 이미지는 어디에도 업로드되지 않습니다.
- 분리된 레이어를 다시 합성하면 원본과 거의 같습니다(예제 그림 기준 PSNR 약 62 dB, 8비트 반올림 오차 수준).

## 사용법

1. `index.html`을 Chrome / Edge / Firefox / Safari에서 엽니다(더블클릭으로 열어도 동작).
2. 이미지를 끌어다 놓거나, 클릭해서 고르거나, `Ctrl+V`로 붙여넣습니다. **예제 그림** 버튼으로 바로 시험해 볼 수 있습니다.
3. 자동으로 분리가 실행됩니다. 오른쪽 레이어 패널에서
   - 눈 아이콘: 표시/숨김
   - 레이어 클릭: 혼합 모드 · 불투명도 변경, 해당 레이어만 PNG로 저장
   - 이름 더블클릭: 이름 변경
4. **PSD 다운로드**를 누르면 패널에서 바꾼 내용(이름, 혼합 모드, 불투명도, 표시 여부)이 그대로 PSD에 반영됩니다.

미리보기 상단의 `합성 / 원본 / 선택 레이어 / 차이 ×8`로 결과를 비교할 수 있고, 휠로 확대 · 드래그로 이동합니다.

## 레이어 구성 (위 → 아래)

| 레이어 | 혼합 모드 | 내용 |
|---|---|---|
| 러프 (추정) | 표준 45%, 숨김 | 완성본에서 역으로 만든 **추정** 스케치. 흔들린 연필선 느낌으로 생성 |
| 선화 | 표준 | 선 색과 안티에일리어싱 알파를 역산한 선 |
| 효과 | 스크린 ↳ | 넓게 퍼진 빛 · 글로우 등 나머지 밝아짐 |
| 반짝임 | 스크린 ↳ | 작고 밝은 점(눈 하이라이트, 별, 스파클) |
| 하이라이트 | 스크린 ↳ | 밑색보다 확실히 밝은 면(머리카락 광택 등) |
| 명암 | 곱하기 ↳ | 부드러운 음영 · 그라데이션 등 나머지 어두워짐 |
| 그림자 | 곱하기 ↳ | 밑색보다 확실히 어두운 면(셀 그림자) — 면마다 한 가지 색 |
| 채색 (그룹) | 통과 | 밑색. 옵션에 따라 색마다 한 레이어(`채색 01 #7B56B5` …) |
| 배경 | 표준 | 테두리와 이어진 단색/완만한 그라데이션 배경(감지된 경우) |

↳ 표시는 채색 그룹에 클리핑된 레이어입니다(옵션으로 끌 수 있음).

## 동작 원리

1. **선화 검출** — 밝기의 블랙 탑햇(closing − 원본)으로 얇고 어두운 구조만 뽑고, 히스테리시스로 이어 붙입니다.
   선 교차점처럼 넓어진 부분은 선에서 이어서 채웁니다.
2. **선 아래 색 복원** — 선 영역을 바깥쪽부터 한 겹씩 이웃 색으로 채운 뒤(인페인팅),
   `원본 = 알파 × 선색 + (1 − 알파) × 아래색` 식으로 선의 색과 알파를 역산합니다.
3. **배경 분리** — 이미지 테두리의 대표 색에서 시작해 선을 넘지 않고 비슷한 색으로 퍼져 나갑니다.
4. **재질 분할** — Lab 색공간 k-means → 연결 영역 → 인접 그래프. 두 영역의 경계가 **선으로 막혀 있지 않고**
   색이 같은 재질의 명암 관계(비슷한 색상, 명도 차이)라면 같은 재질로 묶습니다. 셀 채색에서 재질 경계에는 선이 있고
   그림자 경계에는 선이 없다는 점을 이용합니다.
5. **톤 분석** — 재질마다 다시 군집화해 톤을 나누고, 가장 넓은 톤을 밑색으로 삼습니다.
   선으로 나뉜 같은 재질(앞머리/뒷머리 등)은 밑색을 맞춥니다. 밑색보다 확실히 어두운 톤은 그림자, 밝은 톤은 하이라이트입니다.
6. **역산** — 픽셀마다 `채색 × 그림자 × 명암 → 스크린(하이라이트, 반짝임, 효과) → 선화`로 원본이 나오도록
   곱하기/스크린 값을 계산합니다. 남는 밝아짐은 화이트 탑햇과 조각 크기로 반짝임과 효과로 나눕니다.
   곱하기·스크린 레이어는 "색 + 최소 알파" 형태로 저장해 레이어만 봐도 모양을 알아보기 쉽습니다.
7. **PSD 작성** — 자체 구현한 작성기(RGB 8비트, PackBits RLE, 그룹, 클리핑, 혼합 모드, 유니코드 이름, 병합 이미지)로 저장합니다.

무거운 계산은 Web Worker에서 돌고, 워커를 쓸 수 없는 환경에서는 메인 스레드에서 처리합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| 처리 해상도 | 긴 변 기준으로 줄여서 처리(기본 2048px). 2048px 기준 약 6~8초 |
| 선 감도 | 높일수록 옅은 선까지 선화로 봄 |
| 최대 선 굵기 | 이보다 두꺼운 어두운 영역은 선이 아닌 면으로 봄(0 = 해상도에 맞춰 자동) |
| 선 색상 | 원본 색 유지(정확 재현) / 검정 단색 |
| 색상 군집 수 | 처음 영역을 나눌 때의 색 개수 |
| 밑색 병합 강도 | 높을수록 음영 톤을 같은 밑색으로 적극적으로 묶음 |
| 그림자 판정 기준 | 높을수록 옅은 음영도 그림자 레이어로 보냄 |
| 반짝임 최대 크기 | 이보다 작은 밝은 점을 반짝임으로 봄 |

## 한계

- 인공지능 모델이 아닌 영상 처리 휴리스틱입니다. **선이 있는 셀 채색** 그림에서 가장 잘 동작하고,
  선이 없거나 브러시로 칠한 그림은 밑색이 여러 톤으로 나뉘거나 음영이 명암 레이어로 많이 넘어갈 수 있습니다.
- 러프는 원본에 존재하지 않으므로 완성본에서 **생성한 추정 스케치**입니다(기본 숨김).
- 선 아래에 가려진 색은 주변에서 추정한 값입니다.
- 반투명 가장자리(투명 배경 PNG의 외곽)는 근사 처리됩니다.
