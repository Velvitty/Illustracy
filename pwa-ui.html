입력

처리

긴 변이 이 크기보다 큰 그림만 줄입니다. "전부"는 PSD도 줄인 크기, "배경 · 얼굴만"은 PSD가 처리 해상도 그대로. 켜거나 방식을 바꾸면 설명을 보고 확인한 뒤 실행합니다
그림 전체가 크게(45° 넘게) 기울었거나 옆으로 누웠으면 켜세요. 얼굴을 여러 각도(0 · ±30 · ±60 · ±90°)로 찾아 가장 얼굴다운 각도로 이름 · 캐릭터 폴더 · 배경 규칙을 맞춥니다. 똑바른 그림에 켜면 가짜 얼굴이 늘 수 있습니다. 돌려서 저장해 모서리가 흰색 · 투명으로 채워진 그림은 켜지 않아도 기울기를 알아봅니다

선화

0 = 그림에서 선(펜) 굵기를 재서 자동

채색 · 명암

높을수록 음영 톤을 같은 밑색으로 묶음
높을수록 옅은 음영도 그림자 레이어로
0 = 해상도에 맞춰 자동
색이 많은 그림은 높이면 비슷한 색의 다른 부분이 덜 합쳐짐

레이어 구성

파츠별: [피부] [머리카락] … 안에 밑색 · 그림자 · 하이라이트(밑색 색마다 한 폴더). 재질별: [피부] [옷] [머리카락] [눈] [그 밖] 다섯 폴더(재질 식별 신경망). 단계별: [밑색] [1차 그림자] [2차 그림자] [하이라이트] 안에 파츠(클리핑 없이. 불투명한 그림은 합친 결과가 같음)
오프라인 동작 — 이 파일 하나만 있으면 인터넷 없이 실행됩니다. 외부 라이브러리·서버·유료 API를 쓰지 않고, 이미지는 어디에도 업로드되지 않습니다.

레이어 구성 — 작업 파일처럼 [캐릭터] · [배경] 폴더로 나누고, 파츠마다 밑색 → 1차·2차 그림자(곱하기) → 하이라이트를 클리핑으로 쌓습니다(단계별 폴더를 고르면 거꾸로 [밑색] · [1차 그림자] · [2차 그림자] · [하이라이트] 폴더마다 파츠 레이어를 둡니다). 그 위에 그라데이션 · 명암 · 반사광 · 림라이트, [효과](빛, 반짝임), [선화](선화 + 색 트레이스)를 두고, 배경 위 입자는 배경 효과로 나눕니다. 내용이 거의 없는 레이어는 만들지 않으며, 다시 합치면 원본이 재현되도록 계산합니다. 러프는 작가가 이 선화를 긋기 전에 그렸을 밑그림을 거꾸로 짐작한 추정 스케치 두 장(러프 1: 아이디어를 급하게 잡은 첫 러프, 러프 2: 그것을 다듬은 러프)이며 [러프] 폴더 안에 숨김 상태로 둡니다.
